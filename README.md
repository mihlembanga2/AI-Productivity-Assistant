# AI Workplace Productivity Assistant

## Project Overview
A web-based AI-powered productivity platform that helps professionals 
automate common workplace tasks.

## Features
- Smart Email Generator
- Meeting Notes Summarizer
- AI Task Planner
- AI Research Assistant
- AI Chatbot Interface

## Tools Used
- Lovable AI (app builder)
- Claude / ChatGPT (AI backend)
- GitHub (version control & hosting)

## Setup Instructions
1. Open the live link below
2. Choose a tool from the sidebar
3. Fill in the form and click Generate
